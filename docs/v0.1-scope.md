# Rygnal Core v0.1 Scope

## Release Name

`v0.1-core-mvp`

## Goal

Create the first stable local-first core MVP for Rygnal.

## v0.1 Must Prove

Rygnal Core should prove this workflow:

```
Tool request
→ Risk assessment
→ Policy decision
→ Approval workflow if needed
→ Audit logging
→ Safe execution or block
→ Clear CLI output
```

## Included

- Policy Engine (with rule priorities and schema versioning)
- Risk Engine (including Rust AST parsing and subjective recency multipliers)
- Audit Logger (tamper-evident hash chain and SQLite/JSONL backends)
- Interceptor
- Approval Workflow (with local SQLite queue, role RBAC checks, and API endpoints)
- Runtime Modes (Observe, Simulate, Enforce)
- Real Scenario Runner
- CLI Output and TUI prompt UX
- Security Hardening (secret redaction, path traversal checks)
- Docker setup
- Release readiness checklist

## Not Included

- Web dashboard / SaaS platform
- SSO / Enterprise Authentication
- Billing
- Multi-tenancy
- Direct out-of-the-box production agent framework integration (integrated via example adapter wrappers for OpenAI, LangChain, and MCP under `examples/`)
- Production-grade standalone MCP proxy/gateway
- Enterprise deployment / Kubernetes orchestration
- SIEM integrations


## Success Criteria

A developer should be able to:

1. Clone the repo
2. Install dependencies or use Docker
3. Run tests
4. Run the scenario demo
5. Understand the architecture
6. See audit logs generated
7. Understand current limitations
