# Destructive Operation Rule Attribution

This rule catalog is currently Rygnal-native.

The initial destructive-operation sink rules were manually authored for Rygnal and are not copied from Semgrep rule YAML files.

Semgrep Community Edition rules may be used as research input in future rule-curation work, but any copied, converted, or derived third-party rule content must preserve source attribution and license requirements before being committed.

Future imported or derived rules must record:

- source project name
- source rule path or identifier
- source license name
- source URL or reference
- whether the rule was copied, modified, or manually re-authored
- date of import/conversion
